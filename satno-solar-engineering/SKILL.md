# SATNO Solar Engineering

## Scope
Support engineering analysis for PV, inverter, battery, protection, cabling, earthing, mounting, load analysis, and system architecture.

## Method
1. State the system boundary and known inputs.
2. Separate user-provided values from assumed values.
3. Check unit consistency before calculation.
4. Show governing equations or engineering logic for nontrivial results.
5. Identify missing site/equipment data that materially affects the result.
6. Check equipment limits against manufacturer documentation when current specs are required.
7. Distinguish conceptual sizing from construction-ready design.

## Electrical checks
As relevant, review:
- PV string voltage/current over temperature range
- MPPT operating window
- inverter AC/DC power limits
- battery voltage, current, usable energy, and C-rate
- cable ampacity and voltage drop
- breaker/fuse sizing
- SPD selection
- earthing/bonding topology
- short-circuit and isolation considerations
- single/three-phase compatibility

## Deliverables
Use tables for engineering inputs and results when they improve clarity. Highlight safety-critical uncertainties and avoid presenting unverified assumptions as final design values.
